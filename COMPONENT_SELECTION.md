# FPV Drone Component Selection

**Budget:** ~100 EUR  
**Target:** Educational, beginner-friendly, open-source 3D-printable frame

## Recommended Frame: Flywoo FPV Freestyle or DIY Open-Source Design

### Electronics Bill of Materials

| Component | Quantity | Price EUR | Notes |
|-----------|----------|-----------|-------|
| **Motors** | 4x | 20-24 | Brushless (2300-2600 KV), 2S-4S capable (~5-6 EUR each) |
| **ESCs** | 4x | 12-16 | 20A Betaflight-compatible (~3-4 EUR each) |
| **Flight Controller** | 1x | 12-18 | F4 or F7 (Betaflight), 6-DOF gyro |
| **FPV Camera** | 1x | 15-20 | 600-1200 TVL CMOS |
| **VTx (Video TX)** | 1x | 12-18 | 25-200mW, 5.8GHz |
| **Receiver** | 1x | 8-12 | SBUS/PPM compatible (ELRS if budget allows) |
| **Battery** | 1x | 12-15 | 3S 850-1300mAh LiPo, 30-60C |
| **Connectors & Wire** | - | 5-8 | XT30, connectors, shrink tube |
| **Propellers** | 2x sets | 4-6 | Plastic, 5-6 inch |
| **Misc** | - | 5-10 | USB programmer, antenna, dampeners |
| | | | |
| **TOTAL ELECTRONICS** | | **95-127 EUR** | Can optimize by choosing cheaper brands |

### 3D Printed Frame Components

- **Frame material:** PLA or PETG (consider impact resistance)
- **Print time:** ~40-60 hours total across 3 printers (can parallelize)
- **Filament cost:** ~20-30 EUR (500-750g total)
- **Recommended designs:**
  - Flywoo Freestyle (open CAD available)
  - Printables/Thingiverse "Quad" designs
  - Look for: 5" props, modular, repair-friendly

### Budget Optimization Strategies

1. **Find cheap electronics sources:**
   - AliExpress (slower shipping, but very cheap)
   - Local electronics shops
   - Used parts (eBay)

2. **Print multiple spares:**
   - Arms (most-crashed part)
   - Camera mounts
   - Battery holders

3. **Consider minimal FPV first:**
   - Start with analog FPV (cheaper VTx/camera)
   - Can upgrade to HD later

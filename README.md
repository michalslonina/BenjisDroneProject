# FPV Drone for Benjamin

A 3D printable FPV (First Person View) drone project designed for educational and recreational flying with my son Benjamin.

## Project Structure

```
├── cad/                 # 3D models and CAD files
│   ├── frame/          # Drone frame components
│   ├── arms/           # Motor arms
│   └── body/           # Fuselage and housing
├── firmware/           # Flight controller firmware
├── electronics/        # Circuit diagrams and PCB designs
├── docs/              # Documentation and assembly guides
├── slicing/           # Printer settings and slicing profiles
└── builds/            # Build logs and flight test data
```
